# Installation

Vouch consists of two client-side binaries:

- **`vouch`** — The CLI tool for authentication and credential management
- **`vouch-agent`** — A background daemon that manages sessions, caches certificates, and implements the SSH agent protocol

Both are installed together regardless of the installation method.

Choose your platform:

- [macOS](install-macos.md) — Homebrew or direct download
- [Linux](install-linux.md) — APT/DNF packages or direct download
- [From Source](install-source.md) — Build from source with Cargo
