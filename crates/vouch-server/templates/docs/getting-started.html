Getting Started

Start using Vouch in under 5 minutes

Prerequisites

  • YubiKey 5 series (or compatible FIDO2 security key)
  • Server URL: {{ server_url }}

Quick Start

1 Install the CLI
$brew install vouch-sh/tap/vouch

See installation guide for Linux and Windows.

2 Enroll your YubiKey
$vouch enroll --server {{ server_url }}

This opens a browser to verify your identity and register your YubiKey.

3 Login each day
$ vouch login
Enter PIN: ****
Touch your YubiKey...
Authenticated for 8 hours
4 Use SSH, AWS, and Git
# SSH just works
$ ssh user@server
# AWS credentials available
$ aws s3 ls --profile vouch

What happens when you login?

  • Vouch issues an 8-hour SSH certificate signed by your organization's CA
  • Vouch can also issue AWS credentials and GitHub tokens
  • Everything auto-expires — no keys to rotate or revoke
