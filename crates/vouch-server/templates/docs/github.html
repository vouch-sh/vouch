How it works

{{ org_name }} uses a GitHub App to issue short-lived access tokens for your organization's repositories. When you run git clone or git push, the Vouch CLI automatically obtains a token scoped to your organization's repositories. Tokens are valid for 15 minutes and require authentication with your YubiKey.

Multiple GitHub organizations: Your organization can connect multiple GitHub accounts (e.g., acme-corp and acme-oss). Vouch automatically selects the right one based on the repository you're accessing.

Prerequisites

  • Vouch CLI installed and enrolled (vouch enroll)
  • Google Workspace account (personal Gmail is not supported)
  • Organization admin has connected GitHub (see Admin Setup below)
1 Configure Git Credential Helper

Run the setup command to configure git to use Vouch for GitHub authentication. 

# Check status and see configuration
vouch setup github

# Automatically configure git
vouch setup github --configure

This adds the following to your ~/.gitconfig: 

[credential "https://github.com"]
    helper = "/path/to/vouch" credential github
2 Authenticate with Your YubiKey

Log in with your YubiKey to start a session. 

vouch login
3 Use Git Normally

Git operations to GitHub will automatically use Vouch for authentication. 

# Clone a private repository
git clone https://github.com/your-org/your-repo.git

# Push changes
git push origin main

# Pull updates
git pull

Troubleshooting

Authentication failed
Make sure you're logged in with vouch login. Sessions expire after 8 hours.
"Organization has not connected GitHub"
An organization admin needs to visit {{ server_url }}/github/connect to install the GitHub App.
"GitHub requires organizational membership"
GitHub integration only works with Google Workspace accounts. Personal Gmail accounts are not supported.
Repository not accessible
The GitHub App may only have access to selected repositories. Contact your admin to grant access to additional repos.
"Multiple GitHub accounts connected. Specify 'owner'"
Your organization has multiple GitHub accounts connected. This usually resolves automatically based on the repository URL. If you see this error, ensure you're using the full repository URL (e.g., https://github.com/acme-corp/repo.git).
Wrong credential helper being used
Check for conflicting credential helpers with git config --list | grep credential. You may need to remove other helpers for github.com.
