Docker Registry Integration

Authenticate to container registries using {{ org_name }}

How it works

{{ org_name }} provides a Docker credential helper that automatically obtains short-lived tokens for container registries. When you run docker pull or docker push, the Vouch CLI exchanges your session for registry-specific credentials.

Supported Registries

AWS ECR

Elastic Container Registry

*.dkr.ecr.*.amazonaws.*

GitHub

Container Registry

ghcr.io

Prerequisites

  • Vouch CLI installed and enrolled (vouch enroll)
  • Docker installed
  • Underlying cloud integration configured (AWS or GitHub)
1 Configure Docker Credential Helper

Run the setup command to configure Docker to use Vouch for registry authentication. 

# Check status and see configuration
vouch setup docker

# Automatically configure for specific registries
vouch setup docker --configure ghcr.io
vouch setup docker --configure 123456789012.dkr.ecr.us-east-1.amazonaws.com
vouch setup docker --configure 123456789012.dkr.ecr.us-west-2.amazonaws.com

This creates a symlink and updates ~/.docker/config.json: 

{
  "credHelpers": {
    "ghcr.io": "vouch",
    "123456789012.dkr.ecr.us-east-1.amazonaws.com": "vouch"
  }
}
2 Authenticate with Your YubiKey

Log in with your YubiKey to start a session. 

vouch login
3 Use Docker Normally

Docker operations to configured registries will automatically use Vouch for authentication. 

# Pull from AWS ECR
docker pull 123456789012.dkr.ecr.us-east-1.amazonaws.com/my-image:latest

# Pull from GitHub Container Registry
docker pull ghcr.io/my-org/my-image:latest

Registry-Specific Setup

AWS ECR

Docker ECR authentication uses your existing AWS setup. The IAM role must include AmazonEC2ContainerRegistryReadOnly or AmazonEC2ContainerRegistryPowerUser policy. 

vouch setup aws --role arn:aws:iam::ACCOUNT:role/ROLE

See the AWS setup guide for OIDC trust configuration.

GitHub Container Registry

GHCR uses the same GitHub App tokens as Git operations.

First, set up GitHub integration following the GitHub setup guide.

Troubleshooting

"docker-credential-vouch" not found
Ensure ~/.local/bin is in your PATH. Run vouch setup docker --configure to recreate the symlink.
Authentication failed
Make sure you're logged in with vouch login. Sessions expire after 8 hours.
"AWS not configured" error
Run vouch setup aws --role <role-arn> with an IAM role that has ECR permissions. See the AWS setup guide.
"unsupported registry" error
Vouch only supports AWS ECR and GitHub Container Registry. For other registries, use docker login directly.
Credentials not being used
Check your Docker config with cat ~/.docker/config.json and ensure the registry is listed in credHelpers.
