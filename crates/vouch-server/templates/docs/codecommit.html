AWS CodeCommit

Access CodeCommit repositories using short-lived credentials

How it works

git-remote-codecommit is a Git remote helper that uses the AWS credential chain to sign requests to CodeCommit. With Vouch's credential_process in your AWS profile, every git clone, git push, and git pull is authenticated with short-lived STS credentials backed by your YubiKey.

Why git-remote-codecommit?

AWS offers three ways to authenticate to CodeCommit. The codecommit:// protocol with git-remote-codecommit is the only one that works cleanly with short-lived credentials:

HTTPS Git credentials (IAM-generated username/password)
Static credentials that must be rotated manually. Stored in plaintext by most Git credential managers.
aws codecommit credential-helper
Conflicts with macOS Keychain and Git Credential Manager. Known to cause "unable to access" errors when other credential helpers are installed.
git-remote-codecommit (recommended)
Uses the standard AWS credential chain. No conflicts with other credential helpers. Works with credential_process out of the box.

Prerequisites

  • Vouch AWS profile configured — see the AWS setup guide
  • pip install git-remote-codecommit
1 Install git-remote-codecommit 
pip install git-remote-codecommit
2 Clone a Repository

Use the codecommit:// URL scheme with your Vouch AWS profile name. 

# Clone using your Vouch profile
git clone codecommit://vouch@my-repo

# For a specific region
git clone codecommit::us-west-2://vouch@my-repo

The profile name before @ must match your Vouch AWS profile (typically vouch).

3 Use Git Normally

All Git operations work as expected. Vouch provides fresh STS credentials for each operation. 

git add .
git commit -m "Update feature"
git push
git pull

Troubleshooting

"git: 'remote-codecommit' is not a git command"
git-remote-codecommit is not installed or not on your PATH. Run pip install git-remote-codecommit and ensure the pip scripts directory is in your PATH.
Access denied on push/pull
Your IAM role needs codecommit:GitPull and codecommit:GitPush permissions. Check that the profile name in the clone URL matches your Vouch profile.
Conflicts with existing Git credential helper
The codecommit:// protocol bypasses Git's credential helper system entirely, so there should be no conflicts. If you previously configured credential.helper for CodeCommit HTTPS URLs, those settings are ignored for codecommit:// URLs.
