Self-hosted deployment:

  1. Clone the repository: git clone https://github.com/vouch-sh/vouch
  2. Copy .env.example to .env and configure
  3. Run with Docker: docker compose up -d
  4. Configure your reverse proxy (nginx, Caddy, etc.)

Then continue to Step 2 below to connect Google Workspace.

2 Connect Google Workspace

Create OAuth credentials in Google Cloud Console:

  1. Go to console.cloud.google.com/apis/credentials
  2. Create a new project (or select existing) and name it "Vouch"
  3. Configure OAuth consent screen:
    • User Type: Internal (your org only)
    • Scopes: openid, email, profile
  4. Create OAuth 2.0 Client ID:
    • Type: Web application
    • Redirect URI: {{ server_url }}/oauth/callback
  5. Copy Client ID and Client Secret

Restrict enrollment to this email domain
