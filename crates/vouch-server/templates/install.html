Get Started with Vouch

Install the CLI and enroll your YubiKey

Prerequisites
  • FIDO2 security key (YubiKey 5 series recommended)
  • Server URL from your admin (or use {{ server_url }})
1 Install the CLI
$brew install vouch-sh/tap/vouch
# Import GPG key
curl -fsSL https://packages.vouch.sh/gpg/vouch.asc \
| gpg --dearmor \
| sudo tee /usr/share/keyrings/vouch-archive-keyring.gpg > /dev/null
# Add repository
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/vouch-archive-keyring.gpg] https://packages.vouch.sh/apt stable main" \
| sudo tee /etc/apt/sources.list.d/vouch.list > /dev/null
# Install
sudo apt-get update && sudo apt-get install -y vouch
# Add repository
sudo tee /etc/yum.repos.d/vouch.repo << 'EOF'
[vouch]
name=Vouch
baseurl=https://packages.vouch.sh/rpm/$basearch/
gpgcheck=1
gpgkey=https://packages.vouch.sh/gpg/vouch.asc
enabled=1
EOF
# Install
sudo dnf install -y vouch

Limited Windows Support

The Vouch agent and SSH integration are not available on Windows. Only basic authentication and credential exchange are supported.

Download the Windows binary from the releases page, extract the zip file, and add vouch.exe to a directory in your PATH.

Supported: enroll, login, credential aws, credential github

2 Enroll your YubiKey
$vouch enroll --server {{ server_url }}

This opens a browser to verify your identity and register your YubiKey.

3 Daily login
# Start your day with a single touch
$ vouch login
Enter PIN: ****
Touch your YubiKey...
✓ Authenticated for 8 hours

After login, your identity is available to SSH, AWS, Git, and other tools automatically.
